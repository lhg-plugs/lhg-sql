# /lhg-sql:sql-schema —— 表结构卡

用户输入在 `$ARGUMENTS` 中：`<建表语句或数据字典文本>`（可粘贴 `SHOW CREATE TABLE` 结果）。

## 流程

### 1. 解析输入

从建表语句提取：表名、字段名、类型、主键、索引、外键、注释。注释缺失的字段标"含义待确认"，不许猜（如 `status` 可能是订单状态也可能是用户状态，必须问）。

### 2. 输出表结构卡

```markdown
## 表结构卡：<表名>（日期）
| 字段 | 类型 | 主键/索引 | 含义 |
|---|---|---|---|
| id | bigint | PK | 主键 |
| ... | | | 含义待确认 |
关联：<外键指向的表>
数据量级：<用户提供或未知>
```

### 3. 沉淀

表结构卡存下来（如 `docs/schema-<表名>.md`），后续 `/lhg-sql:sql` 直接引用，不用每次重问。

## 硬规则

- 字段含义拿不准 → 标"待确认"并问用户，不许编。
- 用户只给了表名没给结构 → 停下来要结构，不许凭表名猜字段。
